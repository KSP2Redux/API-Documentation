    Class CameraAnchorBlend

    Holds the decaying displacement that carries the flight camera anchor from where it sat before a situation change to where the observer sits after it, turning an anchor teleport into a slide.

    Inheritance
    object
    CameraAnchorBlend
    Namespace: Redux.Cameras
    Assembly: Assembly-CSharp.dll
    Syntax
    public class CameraAnchorBlend
    Remarks

    The displacement is stored in whatever frame the caller recorded the jump in and is never converted here, so this type stays free of the simulation transform hierarchy and can be exercised without a running game.

    Remarks

    Docking stalls the main thread for over a hundred milliseconds while view objects are destroyed and physics is unpacked. Advancing by the real elapsed time there spends most of the blend on one frame that never renders an intermediate position, which is seen as a hard cut. The blend is a visual transition, so it advances in rendered frames rather than wall time.
