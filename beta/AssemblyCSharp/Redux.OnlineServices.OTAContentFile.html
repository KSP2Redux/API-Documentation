    Class OTAContentFile

    A single text file resolved from an OTA content channel, either downloaded fresh or read from cache. This is the post-download form handed to Redux.OnlineServices.IOTAContentAppliers, as opposed to Redux.OnlineServices.OTAManifestEntry which only describes a file listed in a channel manifest.
