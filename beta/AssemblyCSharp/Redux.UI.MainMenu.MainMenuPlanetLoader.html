    Class MainMenuPlanetLoader

    Puts a celestial body's own scaled space prefab behind the main menu, and changes it when the vessel on screen comes from a channel naming a different one.

    Inheritance
    object
    MainMenuPlanetLoader
    Namespace: Redux.UI.MainMenu
    Assembly: Assembly-CSharp.dll
    Syntax
    public class MainMenuPlanetLoader : MonoBehaviour
    Remarks

    The menu is a scaled space view at a size of its own choosing, which is what map view is, so the planet is set up the way the map sets one up rather than the way flight does. The prefab is nested under the scene's own planet, inheriting the rotation and the scale the menu was built around, and that planet is hidden once there is something to hide it behind.
