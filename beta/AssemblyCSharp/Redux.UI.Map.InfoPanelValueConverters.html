    Class InfoPanelValueConverters

    Binding converters that turn a raw reading from TrackingStationInfoPanel into the string the tracking station info panel prints, unit included.

    Remarks

    The panel binds one label per reading, so the unit belongs in the converted string rather than in a second label beside it. The thresholds below preserve the stock panel's formatting. Every group formats with the current culture, which is what puts a comma in "5,29E+22" on a French install.
