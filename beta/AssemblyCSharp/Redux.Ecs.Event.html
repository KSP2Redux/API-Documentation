    Namespace Redux.Ecs.Event

    Classes

    EcsEventAttribute

    Optional settings for the systems generated for an IEcsEvent struct. Generation keys off the interface; the attribute only customizes it.

    EcsEventCleanupGroup

    Hosts the generated per-event-type cleanup systems that trim expired events. Runs once per rendered frame, after the frame's sim fixed-update ticks and just before Update scripts.

    Structs

    EventReader<T>

    Read view over the events a subscriber has not yet processed, for use as a job field. Obtain via GetReader().

    EventSingleton<T>

    A singleton holding the event queue. You generally don't interact with this as it is an implementation detail of Producer<T> and Subscriber<T>.

    EventSingleton<T>.CleanupJob

    EventSingleton<T>.FlushJob

    EventSingleton<T>.UpdateCursorJob

    Converts a subscriber's absolute offset into a relative cursor and unread window for this frame's reader, then advances the offset to the post-flush end of the list.

    EventWriter<T>

    Thread-safe event emitter for use as a job field. Obtain via GetWriter().

    Producer<T>

    Use this to emit events of type T. Call GetWriter() to get access to the EventWriter<T> you use to actually write the events.

    Subscriber<T>

    Use this to subscribe to new events of type T, consuming the events published since the system's last run.

    Interfaces

    IEcsEvent

    Marker interface for unmanaged ECS event payload structs.

    IEcsEventForwarder<T>

    Implement this to have code generation generate the rest of a message forwarding system. You can implement it multiple times on one system.
