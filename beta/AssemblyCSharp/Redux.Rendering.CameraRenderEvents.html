    Remarks

    URP never raises the Camera callbacks. These events forward URP's UnityEngine.Rendering.RenderPipelineManager.beginCameraRendering and UnityEngine.Rendering.RenderPipelineManager.endCameraRendering. The begin event comes before URP culls the camera, so it stands in for both pre-cull and pre-render. Every camera of a stack gets its own pair. Adding a handler connects to URP, so the events also work in edit mode, for example for ExecuteInEditMode components and editor previews.
