    Syntax
    public class VesselMissionProgressComponent : ObjectComponent, IGuidIdentity
    Remarks

    Only missions whose current stage is vessel scoped keep a record here. Docking merges both vessels' records into the combined craft, undocking gives both halves a copy, and losing the vessel loses the progress with it.

    Remarks

    A vessel may only work on a mission picked up before it was built, so this is the value that decides eligibility. It is inherited rather than restamped whenever a vessel is derived from another.
