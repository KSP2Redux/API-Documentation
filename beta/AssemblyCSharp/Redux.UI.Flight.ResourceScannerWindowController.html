    RequiresFullRefresh(string, string)

    Decides whether a vessel change moved the window to another celestial body, which every part of it is keyed to and none of it refreshes on its own.

    Declaration

    Parameters
    Type Name Description
    string displayedBodyName

    Internal name of the body the window currently describes.
    string activeVesselBodyName

    Internal name of the body the active vessel orbits.
    Returns
    Type Description
    bool

    True when the window has to be refreshed whole.
    Remarks

    Switching to a vessel in another sphere of influence is not an SOI transition, so nothing publishes the message the window rebuilds itself on. The identity card, the resource rows and the body material all keep describing the body the previous vessel orbited. Issue #1220. A vessel that reports no body yet returns false rather than forcing a refresh, or the window rebuilds itself every frame for as long as the lookup keeps coming back empty.

    SyncResourceListToBody(VisualElement, string, string)

    Drops the available-resource rows when they were built for a different celestial body, so a resource the body on display does not have cannot stay on screen.

    Declaration

    Parameters
    Type Name Description
    VisualElement resourceList

    The rows container, or null when the window is not built yet.
    string listBodyName

    Internal name of the body the rows were last built for.
    string currentBodyName

    Internal name of the body now on display.
    Returns
    Type Description
    string

    The body name the list is keyed to once this returns.
    Remarks

    The rows are keyed by resource name and reused across repopulations, and the repopulation only ever adds or updates them. Nothing removes the row of a resource the new body lacks, and the active vessel can change body with no SOI transition to hang a clear off, by switching to a vessel elsewhere. That is how Duna's Carbon Regolith row reached Ike, still selectable and still showing the concentration it last read at Duna, on a body that has no Carbon Regolith at all. Issue #1220.
