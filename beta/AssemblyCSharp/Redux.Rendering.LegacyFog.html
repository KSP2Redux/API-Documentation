    Class LegacyFog

    Keeps the fog density KSP2's lighting profiles were authored for.

    Remarks

    Stock fogged the VAB, the colony VAB and the Training Center background with the post-processing stack's deferred fog, which used the raw UnityEngine.RenderSettings.fogDensity: exp2(-density * z) for exponential and exp2(-(density * z)^2) for exponential squared. URP fogs with Unity's fog parameters, which hold density / ln 2 and density / sqrt(ln 2), so the same density comes out denser. The density is scaled for the duration of each rendered frame and restored afterwards, so game code that reads the render settings back, such as DynamicAmbientLight saving a lighting profile, still sees the authored value.
