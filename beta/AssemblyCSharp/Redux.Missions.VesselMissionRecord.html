    Class VesselMissionRecord

    One vessel's progress through the vessel scoped run of a single mission.

    Inheritance
    object
    VesselMissionRecord
    Namespace: Redux.Missions
    Assembly: Assembly-CSharp.dll
    Syntax
    public class VesselMissionRecord
    Remarks

    Describes only the run the mission is currently on, never the whole mission. Stages outside that run either completed globally already or have not been reached, so a record is discarded whole when the run collapses.
