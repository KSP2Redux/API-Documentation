    Class VesselMissionCoordinator

    Moves a mission's live progress between the vessels working on it.

    Inheritance
    object
    VesselMissionCoordinator
    Namespace: Redux.Missions
    Assembly: Assembly-CSharp.dll
    Syntax
    public static class VesselMissionCoordinator
    Remarks

    A mission is evaluated from a single live MissionData, and every condition reads whichever vessel is active, so per-vessel progress is a matter of swapping which record that live object is holding rather than of evaluating anything per vessel. These are the pieces of that swap that do not need a game to run, kept apart so they can be tested without one.

    Remarks

    A null record means the incoming vessel has never worked on this mission, or is not allowed to, and the mission rewinds to the first stage of the run. Only the run is rewound: stages the campaign finished earlier stay finished.
