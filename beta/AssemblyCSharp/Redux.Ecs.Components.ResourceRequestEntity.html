    Class ResourceRequestEntity

    Creates and tears down resource-flow request entities and toggles their active flag. A request entity is the sole identity of a request: it carries RequestVessel (shared, the solve filter), RequestPart, a ResourceFlowRequest header, its own ResourceFlowInstructionData buffer, a ResourceFlowResponse, and a ResourceFlowFailedResource buffer.

    RestampVessel(EntityManager, Entity, Entity)

    Re-stamps RequestVessel on every request whose RequestPart is partEntity. Must run synchronously when a part changes owners: the solve gathers requests by RequestVessel, and the end-of-tick reconcile pass alone would leave one tick where the old vessel's manager rejects them against a graph the part has left.
