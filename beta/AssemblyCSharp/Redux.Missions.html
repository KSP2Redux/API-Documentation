    Namespace Redux.Missions

    Classes

    ActionInfo

    Optional editor-and-author-facing metadata for an IMissionAction implementation.

    InspectorLabel

    Overrides the author-facing label shown for a serialized field in the mission editor. Used when the field's C# name normalizes to something too verbose for the label column (for example waitForSummaryDismissed auto-normalizes to "Wait For Summary Dismissed", which can be shortened to "Wait For Dismiss" via this attribute).

    InspectorSection

    Groups consecutive serialized fields under a bold section header in the mission editor. Use when an action has many fields that naturally cluster (e.g. content vs behavior vs layout). Fields without this attribute render without a section header.

    InspectorTypeFilter

    Declares the base type that a serialized System.Type-typed field's value must derive from. The mission editor reads this to pick an appropriate picker (e.g. MessageCenterMessage picks via the MessageCenter event picker).

    MessageInfo

    Optional editor-and-author-facing metadata for a MessageCenterMessage subclass.

    PropertyWatcherInfo
