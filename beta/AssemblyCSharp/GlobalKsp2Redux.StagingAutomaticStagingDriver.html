    Finds staged engines and separators whose stage contradicts the part structure, among the pairs that involve a changed part.

    Declaration

    Parameters
    Type Name Description
    List<IObjectAssemblyPart> changedParts

    The parts that were just placed, which limit the pairs that are checked.
    List<IObjectAssemblyPart> misorderedParts

    Receives the parts that need a new stage.
    Remarks

    Two orders are wrong. An engine that fires before the separator below it ignites with that stack still attached. A separator that fires before a part it drops throws that part away before it fires. Parts that share a stage are left alone, and so is any pair that no changed part belongs to, so staging the player arranged survives. Of a wrong pair, the part that must fire later is reported.

    TryGetStructuralStageIndex(IObjectAssemblyPart, out int, out bool)

    Chooses the stage of an engine or separator that is not staged yet from where it sits in the part structure.

    Declaration
    public bool TryGetStructuralStageIndex(IObjectAssemblyPart part, out int stageIndex, out bool needsNewStage)
    Parameters
    Type Name Description
    IObjectAssemblyPart part

    The part to place.
    int stageIndex

    When this method returns true, the stack index of the stage that takes the part.
    bool needsNewStage

    When this method returns true, true if a new stage must be inserted at stageIndex first.
    Returns
    Type Description
    bool

    True if the part structure decided a stage, false if the rules for other parts apply.
    Remarks

    Every engine and separator gets a level that says how late it fires. The part tree is cut into segments at the staged separators. The engines of a segment, the ones on the side of a tank as well, wait for the stack separator that closes the segment below. Without one they have level 0, and with one their level is one above it. A separator fires after everything it drops, so its level is one above the highest level among those parts. An engine goes into the stage of the staged engines with the same level that fire after the separator the engine waits for, or with that separator. A separator, or an engine without such a stage, gets a new stage between the staged parts that must fire before it and the staged parts that must fire after it. Staged parts that are not engines or separators count as firing last, as parachutes do. A part in a tree that is upside down, as in a rocket built from the engine up, is left to the rules for other parts. So is a part next to a decoupler that keeps some of the parts under it when it fires, an engine in a segment that stack branches close with more than one separator, and an engine in a craft that has no staged separator, since the player lights those engines one after the other.
