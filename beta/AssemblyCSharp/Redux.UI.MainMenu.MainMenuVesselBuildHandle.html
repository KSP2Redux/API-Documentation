    Class MainMenuVesselBuildHandle

    Owns everything a built main menu vessel brought into the scene: its parts, the throwaway objects used to assemble them, and the materials cloned for it. Disposing tears the whole vessel down in one go, which is what the rotation does before it shows the next one.

    Remarks

    A mesh or a material is not owned by the component it is handed to, so destroying the part it was built for leaves it resident. Anything created for one vessel and not reachable from a renderer afterwards has to be handed over here or the menu accumulates one copy of it per rotation.
