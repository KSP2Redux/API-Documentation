    Struct SerializedModuleData

    Represents the serialized form of a ModuleData object for persistent storage.

    Namespace: KSP.Sim.Definitions
    Assembly: Assembly-CSharp.dll
    Syntax
    public struct SerializedModuleData
    Remarks

    The module payload lives in one of two slots: StateJson carries parsed JSON verbatim (save files, part definitions) without materializing a ModuleData, while the object slot holds a live instance for authoring paths (KSP1 import, captures of in-memory modules). SerializedModuleDataJsonConverter keeps the on-disk shape identical for both slots.
