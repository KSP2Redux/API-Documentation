    Class MainMenuEscapeRouter

    Resolves a single main menu go-back request to at most one open panel.

    Inheritance

    Remarks

    Layers are polled in registration order and the first open one is closed, so a caller registers the innermost panel first. Yield predicates cover panels that already close themselves on the same key press, and any of them reporting open makes the request a no-op rather than closing a layer underneath. The type holds no Unity references and reads no state of its own, which is what lets the ordering be tested without a scene.
