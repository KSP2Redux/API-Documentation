    Class ImageEffectRenderHook

    Runs a source-to-destination image effect on one camera, the URP replacement for OnRenderImage.

    Inheritance

    Syntax
    public sealed class ImageEffectRenderHook : ICameraRenderHook
    Remarks

    The camera colour is copied into a graph texture, which the effect reads as its source and renders back into the camera colour. Built-in pipeline OnRenderImage effects ran after post-processing, so the default event is UnityEngine.Rendering.Universal.RenderPassEvent.AfterRenderingPostProcessing.
