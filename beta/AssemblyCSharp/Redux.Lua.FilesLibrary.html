    Class FilesLibrary

    The Lua Files global for reading and writing files under the calling environment's own folder.

    Inheritance
    object
    FilesLibrary
    Namespace: Redux.Lua
    Assembly: Assembly-CSharp.dll
    Syntax
    [MoonSharpUserData]
public sealed class FilesLibrary
    Remarks

    Sandboxed to a single root: the environment's Location (a mod's folder, or the Lua script folder for the console). All paths are relative to that root and may not escape it. One instance is created per environment because the root differs per environment.
