    Struct SerializedTerrainCollision

    The outcome of checking one patch of an inactive vessel's trajectory against the real terrain of the body it orbits.

    Namespace: KSP.Sim
    Assembly: Ksp2Redux.dll
    Syntax
    public struct SerializedTerrainCollision
    Remarks

    Kept with the vessel in the save so that a patch loaded with the same elements does not have to be checked again. It is only valid for the patch whose elements it carries.

    True if the patch has the same body and nearly the same shape and orientation, false otherwise.
    Remarks

    The epoch and mean anomaly are not compared, since they move on as a vessel thrusts. This is for standing in for a result that is being worked out again, not for deciding that a result is still right.
