    Class GameLifecycleManager

    Drives the live-game Lua lifecycle phases for mod scripts.

    Syntax
    public sealed class GameLifecycleManager : IUpdate, IFixedUpdate
    Remarks

    Mod scripts register closures through the Game global (Update, FixedUpdate, SceneEnter, SceneExit, the named scene wrappers, and the active-vessel event). This manager fires them from the running game's own frame and physics drivers (IUpdate / IFixedUpdate) and its game-state and vessel messages. A single session-long instance accumulates the closures, attaches its drivers to the live game instance, and fans each phase out. One mod's error never aborts the phase for the rest.
