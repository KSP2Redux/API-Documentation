    Returns the world-space position under the cursor, and outputs the raycast hit and the part that was hit.

    Declaration
    public Vector3 GetWorldSpaceCursorPosition(out RaycastHit hitInfo, out IObjectAssemblyPart hitPart, bool hitClosestCollider = false)
    Parameters
    Type Name Description
    RaycastHit hitInfo

    When this method returns, contains the raycast hit for the surface under the cursor, or a default value if no valid part was hit.
    IObjectAssemblyPart hitPart

    When this method returns, contains the assembly part under the cursor, or null if none was found.
    bool hitClosestCollider

    When true, the raycast continues past the first valid hit to find the closest collider. Otherwise it stops at the first valid hit.
    Returns
    Type Description
    Vector3

    The world-space position under the cursor, or the placement-plane intersection point if no valid part was hit.
