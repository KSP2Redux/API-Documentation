    Struct TerrainCrossingJob

    Walks a coasting path against the real terrain and finds the first moment it reaches the ground.

    Namespace: Redux.Planets
    Assembly: Ksp2Redux.dll
    Syntax
    public struct TerrainCrossingJob
    Remarks

    The path is a two body orbit around the body, so it is advanced from one state vector with the universal variable step the impact predictor uses. The terrain turns with the body, so each sample is turned into the body's frame before it is looked up. The step grows with the height above the ground, bounded by the steepest slope a raycast assumes, so a long descent costs a few samples and a low skim keeps the minimum step.
