    Parameters
    Type Name Description
    Vector2[] points

    The data points to plot, where UnityEngine.Vector2.x is the horizontal value and UnityEngine.Vector2.y is the vertical value.

    float height

    The height of the graph box in pixels.
    float width

    The width of the graph box in pixels; when zero the box expands to fill available horizontal space.
