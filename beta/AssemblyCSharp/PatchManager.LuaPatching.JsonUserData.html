    Class JsonUserData

    Lua-facing wrapper exposing a Newtonsoft Newtonsoft.Json.Linq.JToken as a table-like UserData.

    [MoonSharpUserData]
public class JsonUserData
    Remarks

    Patch scripts read and mutate JSON assets through this type: object keys become string indices, array elements become 1-indexed integer indices (matching Lua convention), and iteration is exposed through the __pairs / __ipairs metamethods on Pairs(). Reads against the wrong token type are non-fatal. They log a debug message and return MoonSharp.Interpreter.DynValue.Nil or an empty result. Writes against the wrong token type throw, since silently accepting a write would lose data. Subclasses (IndexedListUserData, ExtensibleJsonUserData) override these members to layer name-indexed lookup or virtual properties on top of the underlying JSON.

    The token to lift, or null for a missing key.
    Returns
    Type Description
    DynValue

    The Lua value for the given token.
    Remarks

    A null token (missing JSON key) maps to MoonSharp.Interpreter.DynValue.Nil. Objects and arrays are wrapped in a fresh JsonUserData. Primitives become the matching MoonSharp.Interpreter.DynValue kind, and Newtonsoft.Json.Linq.JTokenType.None, Newtonsoft.Json.Linq.JTokenType.Null, and Newtonsoft.Json.Linq.JTokenType.Undefined all map to MoonSharp.Interpreter.DynValue.Nil.

    Exceptions
    Type Condition
    ScriptRuntimeException

    Thrown when token's type is not one of the handled token types.

    Remarks

    Lua numbers become integers when they have no fractional part. Lua tables become JSON arrays when their integer length is non-zero, JSON objects otherwise. Nested JsonUserData values are unwrapped to their underlying token. Use the protected overload to disambiguate against an existing slot's type.
