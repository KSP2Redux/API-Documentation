    Class WaitLibrary

    Backs the Lua Wait global with the small set of C# leaf checks its yield loops poll each frame.

    Remarks

    The Wait surface itself is defined in Lua (see Prelude) because MoonSharp cannot yield a host coroutine from inside a CLR call - the loops must run on the Lua side, calling these leaves. Blocking forms (for example Wait.Seconds(2)) yield the calling coroutine until satisfied, so they only work inside a coroutine context (a console body, or a Game.StartCoroutine body). The callback forms (for example Wait.Seconds(2, fn)) are sugar that wraps the blocking form in Game.StartCoroutine, so they also work from a synchronous mod body. "Stop" is the runner ceasing to resume the coroutine, so the loops need no explicit cancel check. Stateless, one shared instance per env.

start) < seconds do\r\n        coroutine.yield()\r\n    end\r\nend\r\n\r\nfunction Wait.Until(predicate, timeoutSeconds, callback)\r\n    if callback ~= nil then\r\n        return Game.StartCoroutine(function()\r\n            local satisfied = Wait.Until(predicate, timeoutSeconds)\r\n            callback(satisfied)\r\n        end)\r\n    end\r\n    local start = leaf.Now()\r\n    while true do\r\n        if predicate() then return true end\r\n        if timeoutSeconds ~= nil and timeoutSeconds > 0 and (leaf.Now() - start) >= timeoutSeconds then\r\n            return false\r\n        end\r\n        coroutine.yield()\r\n    end\r\nend\r\n\r\nfunction Wait.InputDown(key, callback)\r\n    if callback ~= nil then\r\n        return Game.StartCoroutine(function()\r\n            Wait.InputDown(key)\r\n            callback()\r\n        end)\r\n    end\r\n    while not leaf.KeyDown(key) do\r\n        coroutine.yield()\r\n    end\r\nend\r\n\r\nfunction Wait.Input(key, callback)\r\n    return Wait.InputDown(key, callback)\r\nend\r\n\r\nfunction Wait.InputUp(key, callback)\r\n    if callback ~= nil then\r\n        return Game.StartCoroutine(function()\r\n            Wait.InputUp(key)\r\n            callback()\r\n        end)\r\n    end\r\n    while not leaf.KeyUp(key) do\r\n        coroutine.yield()\r\n    end\r\nend\r\n\r\nfunction Wait.InputHeld(key, holdSeconds, callback)\r\n    if callback ~= nil then\r\n        return Game.StartCoroutine(function()\r\n            Wait.InputHeld(key, holdSeconds)\r\n            callback()\r\n        end)\r\n    end\r\n    local held = 0.0\r\n    local last = leaf.Now()\r\n    while true do\r\n        local now = leaf.Now()\r\n        if leaf.KeyHeld(key) then\r\n            held = held + (now - last)\r\n            if held >= (holdSeconds or 0.0) then\r\n                return\r\n            end\r\n        else\r\n            held = 0.0\r\n        end\r\n        last = now\r\n        coroutine.yield()\r\n    end\r\nend\r\n\r\nfunction Wait.Event(eventName, timeoutSeconds, callback)\r\n    Log.Warning(\"Wait.Event('\" .. tostring(eventName) .. \"') is not implemented yet.\")\r\n    if timeoutSeconds ~= nil and timeoutSeconds > 0 then\r\n        return Wait.Seconds(timeoutSeconds, callback)\r\n    end\r\n    return false\r\nend\r\n"
