    Class FeatureEditorViewModel

    The feature editor: every mod's features with a switch each, kept consistent with the feature registry's requirements and conflicts, and the requested set the player applies.

    Inheritance
    object

    public class FeatureEditorViewModel : ViewModelBase
    Remarks

    The rows switch requested features. What ends up on is the registry's resolution of the request, so a requirement turns its target on and locks it, and a feature that would conflict is locked off.

    IReadOnlyCollection<string> listed

    The only features to list, or null to list every one. A mod is listed when its own feature or any of its others is. Unlisted features still count, so they lock what they require and conflict with.
    Remarks

    Features whose requirements no installed mod meets are left out, as is the always-on modding framework, and each mod's default feature, which its mod row stands for. Hidden features stay requested as they came. Redux's own mod comes first, then the rest by name.

    Remarks

    Switching a mod on also turns on its recommended features. Switching a mod off drops the mod's own requested features with it, so a mod is never held on only by features the player can no longer see as the reason.
