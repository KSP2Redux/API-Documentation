    Class WindowViewContext

    Adapts an open window request to the game's UI view lifecycle.

    Remarks

    Register before loading the window. A closed context cancels pending presentation as well as visible UI. Temporary hiding is handled by the window's existing F2 support and does not cancel its context. Omitting allowed views binds the request to the current screen. Supplying several views permits transitions between those screens. Campaign unload always ends the request, including when a load fails. Pass an owner to close its requests through CloseWindowContextsForOwner(object). The UI manager does this for removed vessels using their global identifiers. Other owners call it during teardown. Pass a parent to close a child picker with its enclosing window or settings submenu.
