    Codegen will then emit a managed passthrough property on the corresponding Data_ class and the generated state class. You can opt into the field being serializable by setting Serialized to true.

    Properties

    FieldName

    Overrides the name of the generated passthrough property on the Data_* type and the generated state struct. Defaults to the field name in PascalCase. The serialized key is taken from the field name, not this, so overriding it does not change saves. Must differ from the backing field name (e.g. prefix the field with an underscore) to avoid a member collision.
