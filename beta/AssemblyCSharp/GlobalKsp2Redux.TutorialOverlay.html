    Class TutorialOverlay

    Post-process effect settings for the KSP tutorial overlay, configuring line and background tint parameters.

    Inheritance
    object
    PostProcessEffectSettings
    TutorialOverlay
    Namespace: GlobalKsp2Redux
    Assembly: Ksp2Redux.dll
    Syntax
    public sealed class TutorialOverlay : PostProcessEffectSettings
    Remarks

    Stock post-processing profiles serialize these settings, so the class keeps its Post Processing Stack v2 layout. Redux converts it to TutorialOverlayEffect, which renders before URP post-processing as the package's before-stack effect did.
