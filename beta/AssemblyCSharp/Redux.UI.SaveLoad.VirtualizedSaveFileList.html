    Class VirtualizedSaveFileList

    Keeps only the save list rows that can actually be seen alive, recycling them through the entry pool as the list scrolls. A campaign with two hundred saves costs the same to display as one with ten.

    Remarks

    The campaign load menu lives in a bundled prefab that cannot be edited, so everything here is wired at runtime. Binding takes over layout from the content object's UnityEngine.UI.VerticalLayoutGroup and UnityEngine.UI.ContentSizeFitter, which cannot lay out rows that do not exist, and positions rows directly instead. Row pitch comes from those same components so it still follows the prefab.
