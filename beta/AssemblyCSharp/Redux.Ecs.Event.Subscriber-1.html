    Struct Subscriber<T>

    Use this to subscribe to new events of type T, consuming the events published since the system's last run.

    Namespace: Redux.Ecs.Event
    Assembly: Assembly-CSharp.dll
    Syntax
    public struct Subscriber<T> where T : unmanaged, IEcsEvent
    Type Parameters
    Name Description
    T
    Remarks

    Call Initialize(ref SystemState) in OnCreate, Update(ref SystemState) at the start of OnUpdate, and Dispose() in OnDestroy. Then schedule the read job with the implicit dependency.

    ScheduleParallel<TJob>(TJob, int, ref SystemState)

    Schedules an Unity.Jobs.IJobParallelForDefer over this frame's unread events and chains it into state.Dependency. The iteration count is resolved when the job starts (after the flush). Read the events via EventReader<T> (whose indexer maps the job index to the matching unread event) or AsDeferredJobArray().
