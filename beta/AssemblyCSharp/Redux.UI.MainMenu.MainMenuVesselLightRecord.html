    Class MainMenuVesselLightRecord

    What a menu part's lights and lit surfaces are, kept so they can still be switched once the modules that described them are gone.

    Inheritance
    object
    MainMenuVesselLightRecord
    Namespace: Redux.UI.MainMenu
    Assembly: Assembly-CSharp.dll
    Syntax
    public class MainMenuVesselLightRecord : MonoBehaviour
    Remarks

    A menu craft has no vessel behind it, so the builder destroys every part module the moment it has read their state. That takes the authoring with it: which lights belong to a lamp, how bright each is meant to be, and which materials on a crew pod are its windows. This is written while the modules are still there and read long after they are not.

    Remarks

    Kept rather than left on the light because the menu draws a craft at whatever size frames it, and a light's reach is not a distance that scales with the thing it is attached to. A lamp authored to fill a cabin lights a fraction of one drawn several times life size.
