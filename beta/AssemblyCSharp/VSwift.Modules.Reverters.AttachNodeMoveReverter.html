    Remarks

    In flight, the part prefab loads fresh, so transformers whose effects are persisted via SaveInformation() do not need their reverters re-run. Reverters that operate on the live UnityEngine.GameObject (transform activation, material state) must run in flight to undo prefab-default state that conflicts with the active variant. True if the reverter operates on prefab-loaded GameObject state and must fire during flight init, false otherwise.
