    SortTransparentLayers(Transform, Vector3, List<Renderer>, ref int)

    Draws a scaled body's transparent layers (atmosphere shells, clouds, rings) before those of every body nearer the camera, by a sorting order from the body's distance.

    Declaration
    public static void SortTransparentLayers(Transform body, Vector3 cameraPosition, List<Renderer> layers, ref int hierarchyCount)
    Parameters
    Type Name Description
    Transform body

    The root of the body's scaled visual.
    Vector3 cameraPosition

    The position of the camera that draws the body.
    List<Renderer> layers

    The caller's cache of the body's renderers, refilled when its hierarchy changes.
    int hierarchyCount

    The hierarchy count the cache was filled at, -1 to refill it.
    Remarks

    Transparents sort by render queue before distance, so every body's clouds drew after every body's atmosphere, and Jool's clouds covered the atmosphere of Laythe in front of them (#2156). The sorting order comes first, so the bodies sort back to front as wholes, and within a body the queues keep its layers in order. Every order is negative, so what is not a body (orbit lines, spheres of influence, icons) still draws after the bodies, as its later queues had it.
