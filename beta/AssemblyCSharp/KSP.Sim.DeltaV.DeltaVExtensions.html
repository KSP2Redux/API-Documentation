    ClampSituationToBody(DeltaVSituation, double, double)

    Coerces a situation into a combination the given body actually supports: airless bodies force vacuum at zero altitude, and altitudes are clamped to the body's atmosphere or terrain ceiling.

    Declaration
    public static DeltaVSituation ClampSituationToBody(DeltaVSituation situation, double atmosphereDepth, double maxTerrainHeight)
    Parameters
    Type Name Description
    DeltaVSituation situation

    The situation to coerce.
    double atmosphereDepth

    The body's atmosphere depth in meters; zero or less means airless.
    double maxTerrainHeight

    The body's highest terrain in meters.
    Returns
    Type Description
    DeltaVSituation

    The coerced situation.
    Remarks

    Defensive (#1000): mirrors the clamping the delta-V tool applies when a body is picked, so a situation read from a craft file cannot feed the delta-V maths values the UI would never produce and then displays clamped, making the shown altitude disagree with the computed one.

    TrySyncStageDeltaVSituationLength(List<DeltaVSituation>, int, DeltaVSituation, bool, List<DeltaVSituation>)

    Reconciles a stage situation list against the number of stages in the staging stack, padding with padding when short and trimming from the tail when long.

    Declaration
    public static bool TrySyncStageDeltaVSituationLength(List<DeltaVSituation> situations, int stageCount, DeltaVSituation padding, bool isLoadingCraft, List<DeltaVSituation> droppedEntries = null)
    Parameters
    Type Name Description
    List<DeltaVSituation> situations

    The stage situation list to reconcile.
    int stageCount

    The number of stages the list must describe.
    DeltaVSituation padding

    The situation to add for stages that have no entry yet.
    bool isLoadingCraft

    True while a craft is loading, which skips the reconciliation entirely.
    List<DeltaVSituation> droppedEntries

    Optional list that receives the trimmed entries, tail first.
    Returns
    Type Description
    bool

    True when the list was modified, false when it already matched or was left alone.
    Remarks

    Fixes #1000: the staging stack is rebuilt one stage at a time while a craft loads, so reconciling against its transient count trims the situations just restored from the craft file off the tail.
