    Class FeatureAssetIndex

    Decides which addressable locations the active feature set lets the game load, from an index of the loaded Addressables catalogs, and the helpers the asset loading paths use to apply it.

    Inheritance
    object
    FeatureAssetIndex
    Namespace: Redux.Features
    Assembly: Ksp2Redux.dll
    Syntax
    public static class FeatureAssetIndex
    Remarks

    A location from a mod's catalog needs that mod's default feature on. On top of that, every feature:ModId:FeatureId label it carries must be on and every nofeature:ModId:FeatureId label off, the same rule prefab patches and config entries follow. An untagged location from the game's own bundles in a content label belongs to that label's Ksp2Redux category, the same one Redux's content of that kind is tagged with. The game's own locations outside content labels always load, since the game itself depends on them. Until a feature set activates every helper passes locations through unchanged.
