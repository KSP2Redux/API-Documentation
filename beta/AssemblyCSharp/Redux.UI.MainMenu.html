    Namespace Redux.UI.MainMenu

    Classes

    MainMenuCameraTurn

    Tracks how far the menu's camera has turned while the planet behind it is being changed.

    MainMenuDeployableRecord

    What a part the craft was saved with open needs told, kept until the craft is switched on.

    MainMenuHostPlanet

    Dresses the menu scene's own planet as Duna, for the menu to open on while a real body loads behind it.

    MainMenuMath

    Everything the main menu works out for itself: which body a channel named, where a planet and a craft belong on screen, and the shapes they move along between one arrangement and the next.

    MainMenuPlanetInstance

    One celestial body's scaled space prefab, as the main menu draws it.

    MainMenuPlanetLoader

    Puts a celestial body's own scaled space prefab behind the main menu, and changes it when the vessel on screen comes from a channel naming a different one.

    MainMenuPlanetTracker

    Holds which planet the main menu shows behind whatever vessel is on screen.

    MainMenuRotationTuning

    How long a craft takes to leave and to arrive, and a way to watch it happen on demand.

    MainMenuStickerProjector

    Projects a saved sticker onto a built menu vessel. The stock sticker module drives itself from simulation state a menu vessel does not have, so the decal is projected here instead.

    MainMenuSunLight

    The menu's sun: the light everything is lit by, and the flares that are the sun on screen.

    MainMenuVesselBuildHandle

    Owns everything a built main menu vessel brought into the scene: its parts, the throwaway objects used to assemble them, and the materials cloned for it. Disposing tears the whole vessel down in one go, which is what the rotation does before it shows the next one.

    MainMenuVesselCreditController

    Shows who is credited for the vessel the main menu is displaying, and what they called it.

    MainMenuVesselCreditTracker

    Holds the credit for whichever vessel the main menu rotation currently has on screen.

    MainMenuVesselInstances

    Carries the build handle on the vessel root, so code holding only the object can reach the handle that owns it.

    MainMenuVesselLightRecord

    What a menu part's lights and lit surfaces are, kept so they can still be switched once the modules that described them are gone.

    MainMenuVesselLights

    Turns a menu craft's own lights on, for the bodies where the sun is not enough to see it by.

    MainMenuVesselPlumeSource

    Marks a part whose engine effects run when the craft is under way.

    MainMenuVesselPlumes

    Whether a menu craft's engines are firing.

    MainMenuVesselPoses

    The attitudes the menu shows a craft at.

    MainMenuVesselRotationSession

    Runs the main menu's vessel rotation: picks a target, loads or builds it, shows it for a while, then moves on. Targets come from the loader's own addressable prefabs and from any OTA workspaces published, and the two are handled differently enough that most of this class is about keeping the difference invisible.

    MainMenuWorkspacePartVisualBinding

    A built part paired with the visual state read from the saved part it came from.

    MainMenuWorkspacePartVisualState

    The visual state read from a saved part: its colours, and the module data whose meshes have to settle before the look can be applied.

    MainMenuWorkspaceVesselBuilder

    Builds a display-only vessel from a saved workspace file, for the main menu to rotate through. Parts are instantiated and dressed to look right and nothing more, since none of this is simulated.

    MainMenuWorkspaceVesselTarget

    Turns a built vessel in place, which is the whole of what a menu craft does while it is being looked at.

    ReduxLinksController

    Wires the main menu's external link buttons to the sites they open, and gives each one a tooltip.
