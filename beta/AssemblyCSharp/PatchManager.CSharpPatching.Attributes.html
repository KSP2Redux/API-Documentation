    Namespace PatchManager.CSharpPatching.Attributes

    Classes

    AfterAttribute

    Runs after every patch from these mods.

    AfterPatchAttribute

    Runs after these patches when present.

    BeforeAttribute

    Runs before every patch from these mods.

    BeforePatchAttribute

    Runs before these patches when present.

    ConflictsAttribute

    Refuses to run alongside these mod IDs.

    ConflictsPatchAttribute

    Refuses to run alongside these patches.

    EarlyAttribute

    Runs the patch in the Early pass.

    FirstAttribute

    Runs the patch before Default and Last patches in its pass.

    HasAttribute

    Requires the asset to expose a key, optionally with a sibling predicate method run against the value at that key.

    HasNoAttribute

    Requires the asset to not expose a key.

    LastAttribute

    Runs the patch after First and Default patches in its pass.

    LateAttribute

    Runs the patch in the Late pass.

    NamedAttribute

    Targets only the assets with these names. Supports * and ? wildcards.

    NeedsAttribute

    Requires these mod IDs to be loaded.

    NeedsPatchAttribute

    Requires these other patches to run.

    NotNamedAttribute

    Rejects the assets with these names. Supports * and ? wildcards.

    PMPatchAttribute

    Marks a class as a C# patch group. Its methods carrying a per-domain patch attribute are discovered and registered with the universe at load time.

    PatchAttribute

    Base for the per-domain patch-target attributes. Each subclass bakes the converter name and addressables label so patch authors never type those strings. Concrete attributes ship with their domains.

    RequiresAttribute

    Gates the patch on a predicate method declared on the same class. The method takes the asset wrapper and returns a bool.

    Interfaces

    IPatchModifier

    An attribute that contributes ordering or targeting to the patch it decorates, mirroring one of the PatchDefinition fluent methods. The discovery applies every modifier on a patch method to its PatchDefinition.
