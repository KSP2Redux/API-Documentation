    Class TutorialOverlayEffect

    The KSP tutorial overlay: tints the scene and outlines depth edges, drawn before URP post-processing.

    Remarks

    The URP counterpart of the stock TutorialOverlay Post Processing Stack v2 effect, which the package injected before its built-in stack. Redux.Rendering.PostProcessing.TutorialOverlayHook renders it with the ported Hidden/KSP/TutorialOverlay shader. The parameters and defaults are the stock effect's.
