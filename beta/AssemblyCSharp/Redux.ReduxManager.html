    Class ReduxManager

    Owns the core Redux settings and the always-loaded Redux Manager object, and sets up logging at startup.

    Inheritance
    object
    ReduxManager
    Namespace: Redux
    Assembly: Ksp2Redux.dll
    Syntax
    public class ReduxManager : MonoBehaviour
    Remarks

    It is a MonoBehaviour so that systems without one of their own can run coroutines on it, and so that it can flush buffered log providers every frame.
