    SceneViewHandleAttribute

    Marks a Vector3 or Vector3d field for inspector-driven SceneView handle editing.

    TransformGroupAttribute

    Marks a string field whose value is a bare Transform name that the runtime resolves to ALL matching transforms in the part hierarchy via FindModelTransforms / FindChildren.

    TransformNameAttribute

    Marks a string field as the bare leaf name of a single Transform within the part hierarchy. The runtime resolves the stored value to one specific Transform via recursive name search (FindChildRecursive / FindModelTransform / equivalent).

    TransformPathAttribute

    Marks a string field that holds a slash-separated path to a Transform within the part hierarchy. The runtime resolves the stored value via transform.Find(path), which interprets slashes as hierarchy levels.

    UnitAttribute

    Declares the unit suffix shown after a serialized field's value in author-facing editors.
