    Class PropertyWatcherInfo

    Optional editor-and-author-facing metadata for a PropertyWatcher subclass.

    Inheritance

public class PropertyWatcherInfo : Attribute
    Remarks

    Decorating a watcher with this attribute lets the mission editor render it correctly in the PropertyCondition picker and row UI. All fields are optional and fall back to safe defaults when absent, so existing watchers compile unchanged.

    Category

    Shared picker bucket. Many watchers may share the same Category (for example "Vehicle", "Orbit", "Resource", "Camera"). Free-form string. The picker groups by Category and falls back to "Uncategorized" when null.

    InputDescription

    Author-facing label for the watcher's optional input string parameter (for example "part name", "resource name", "celestial body name"). Visibility of the input field on the condition row is decided by reflection on the watcher's GetValueX(string) and GetValueX(MissionData, string) overrides, not by this field. Null falls back to a generic "input" label.
