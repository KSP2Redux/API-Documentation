    Class ModRequire

    A require implementation that resolves and runs modules against the calling mod's forked environment instead of the shared root globals.

    Inheritance

    Remarks

    MoonSharp's stock require resolves the module name and runs the module against the root global table, so the ModScriptLoader would never see the per-mod ModId/Location and a required module would lose access to that mod's globals. Installing this on each forked environment forwards the environment to MoonSharp.Interpreter.Script.RequireModule(string, MoonSharp.Interpreter.Table) as its global context, which both feeds the loader the right mod id and runs the module with that environment as its _ENV (so nested requires re-enter against the same env). Results are cached per environment via a weak-keyed table, so a module shared by two mods runs once per mod and the cache drops when the env is collected.
