    Namespace SpaceWarp2.API.Config

    Classes

    BooleanType

    A boolean config value, stored as a bool.

    ColorType

    A color config value: a LuaColor on the script side, a UnityEngine.Color in storage so the settings menu renders it as a color picker. Accepts a LuaColor or a table (keyed {r=, g=, b=, a=} or indexed {1, 0.5, 0, 1}) when serializing.

    ConfigBuilder

    Fluent builder for a config entry. Accumulates the entry's shape and binds it at Bind(), returning a live ConfigHandle.

    ConfigHandle

    A live view over a bound config entry. Reads and writes go through the entry's config type, so scripts see rich values while storage holds the C# value the settings menu renders.

    ConfigTypeAttribute

    Marks an IConfigType implementation as a config type and names the Lua global it is exposed under. Discovered across every loaded assembly, so a mod ships its own config types by tagging them.

    ConfigTypes

    The registry of config types. Discovers every IConfigType tagged with ConfigTypeAttribute across the loaded assemblies, contributes them as globals on a mod environment, and resolves a stored value's C# type back to its config type for cross-mod reads.

    ConfigView

    A read/write view over a config file - a mod's own, or another mod's via Config:Mod(id). Reaches existing entries with Get(string, string); it cannot define new ones (defining is an own-config operation).

    DoubleType

    A floating-point config value, stored as a double.

    IntegerType

    An integer config value, stored as an int.

    LuaColor

    The Lua-side representation of a color config value.

    ModConfig

    The Lua Config global - a mod's own config namespace. Declare entries through Define(string, string), fetch existing ones through Get(string, string), and reach another mod's config through Mod(string).

    StringType

    A string config value, stored as a string.

    Interfaces

    IConfigType

    Maps a mod's rich Lua config value to the C# storage value an IConfigEntry holds, and back.
