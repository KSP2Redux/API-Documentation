    Class ModScriptRuntime

    The SpaceWarp-owned Lua mod runtime. Forks per-mod environments off the game's root runtime (IScriptRuntime), contributes the general mod-loading globals, runs registered IModEnvContributors, and executes mod bodies.

    Inheritance
    object
    ModScriptRuntime
    Namespace: SpaceWarp2.API.Lifecycle
    Assembly: SpaceWarp2.dll
    Syntax
    public static class ModScriptRuntime
    Remarks

    SpaceWarp owns env creation and execution. PatchManager and others contribute their own globals through IModEnvContributor. A mod that runs several files in one environment uses CreateModEnv(SpaceWarpPluginDescriptor) once and RunBodyIn(Table, string, string) per file.

    Remarks

    Reads fall through to the root globals, writes stay local to the child, so each mod is isolated on the one shared VM. The runtime contributes the general mod-loading globals (ModId, Location, the require loader, and the Log logger), then runs every registered contributor.
