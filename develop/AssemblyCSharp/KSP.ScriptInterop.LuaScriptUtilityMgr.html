    Class LuaScriptUtilityMgr

    Reflection facade for the script-run lifecycle, kept at this type name for the SpaceWarp console.

    Inheritance
    object
    LuaScriptUtilityMgr
    Namespace: KSP.ScriptInterop
    Assembly: Assembly-CSharp.dll
    Syntax
    public static class LuaScriptUtilityMgr
    Remarks

    The console lives in a SpaceWarp package that cannot reference this game assembly, so it drives script runs by reflecting these static methods by name. The real state lives in ScriptRunRegistry. The Lua surface this manager used to register (Input, Script, Log, Wait, Files) moved to the contributed libraries in Redux.Lua. Do not rename or change these signatures without updating the console's reflection in SpaceWarpConsoleLuaService.
