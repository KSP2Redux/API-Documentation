    Class BenchmarkScenarioRunner

    Owns direct game transitions and temporary input and save restrictions for one benchmark run.

    Inheritance
    object
    BenchmarkScenarioRunner
    Namespace: Redux.Benchmark
    Assembly: Ksp2Redux.dll
    Syntax
    public class BenchmarkScenarioRunner
    Remarks

    Create only after an explicit start request. The caller must keep ticking through cancellation and recovery until IsFinished. The owning component must survive GameManager's normal session teardown.
