    Class PredictedAtmosphericPath

    One continuous run of a forecast, in the form the map renderer wants it.

    Inheritance
    object
    PredictedAtmosphericPath
    Namespace: Redux.Simulation.ImpactPrediction
    Assembly: Assembly-CSharp.dll
    Syntax
    public sealed class PredictedAtmosphericPath
    Remarks

    A managed copy of the forecast's points, since the map reads them on its own schedule. A run is the stretch between two coasts, which are crossed analytically with no points, and the conic across the following coast hangs off the same object. Positions are in the frame the stock orbit sources emit.

    Remarks

    A coast conic is flagged as a patch being flown so the map keeps markers on it. Nothing else owns that flag, so the run a newer one replaces has to clear it, or the map goes on drawing the apoapsis of an orbit that has been recomputed since.
