    Class FfxUpscaler

    AMD FSR 3.1 and FSR 4 as a URP upscaler, through AMD's FidelityFX API and Redux's ReduxFfx native plugin.

    Inheritance
    object

    Syntax
    public sealed class FfxUpscaler : AbstractUpscaler
    Remarks

    Unity 6.6 has FSR 2 only. AMD ships FSR 3.1 and FSR 4 as signed providers behind one loader, which run on Direct3D 12 only. FSR 4 is a machine-learning upscaler for Radeon RX 7000 and newer cards, and the loader offers it only where the card can run it. FSR 3.1 runs on any vendor.

    The upscaler takes the pipeline asset's FSR2Options, which URP finds by type, so the FSR 2 quality and sharpening settings drive it too, and TemporalUpscaling sets them before selecting it. The provider comes from RequestedMajorVersion. Each camera's context owns a slot in the native plugin, whose FidelityFX context is created, dispatched and destroyed on the render thread, and the dispatch adds UpscalerReactiveMask's mask as the reactive mask.
