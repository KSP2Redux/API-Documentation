    Class PassDefinition

    A named patch pass and the passes it is ordered against.

    Inheritance
    object
    PassDefinition
    Namespace: PatchManager.LuaPatching
    Assembly: Assembly-CSharp.dll
    Syntax
    [MoonSharpUserData]
public class PassDefinition
    Remarks

    Passes are full sweeps over every patched label, run in the order their constraints sort into. A declared pass starts out after EARLY and before LATE. Order that no constraint states is left to the sort and may differ between runs.
