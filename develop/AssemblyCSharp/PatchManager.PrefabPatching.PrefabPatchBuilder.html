    Class PrefabPatchBuilder

    Fluent C# frontend that generates the same declarative public manifest used by visual prefab-variant compilation.

    Inheritance
    object
    PrefabPatchBuilder
    Namespace: PatchManager.PrefabPatching
    Assembly: Assembly-CSharp.dll
    Syntax
    public sealed class PrefabPatchBuilder
    Remarks

    Calls only mutate an in-memory PrefabPatchManifest. Call Build() to inspect or serialize it, or Register() during mod initialization to add it to the current runtime registration window. Dependency and ordering methods share the IPatchRelationships model used by ordinary JSON patches.
