    Remarks

    SRP Core's FSR2IUpscaler fills only the colour, depth and motion vector slots of the native texture table. This subclass records the same dispatch and adds UpscalerReactiveMask's mask as FSR 2's reactive mask when the camera has one. Context creation, jitter, resolution and mip bias are the base class's. It registers under its own name with the same FSR2Options, so the pipeline asset's FSR 2 options drive both, and TemporalUpscaling selects it.
