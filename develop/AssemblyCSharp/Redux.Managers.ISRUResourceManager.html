    ScanStateVersion

    Counts the times a resource has actually changed scanned state.

    Declaration
    public static int ScanStateVersion { get; }
    Property Value
    Type Description
    int
    Remarks

    Scanned state is a plain flag on each chart, with nothing to subscribe to when it changes, and more than one thing writes it: a scanner finishing, an agency save being loaded, the debug window. UI that has to follow it compares this against what it last read rather than polling every chart of every body, or worse, only reading it when the player happens to reselect something.

    GetDensityMapPixel(double, double, int, int, out int, out int)

    Converts a normalized longitude and latitude into pixel coordinates on a density map. Both axes are clamped to the last valid pixel. Rounding sends the final half pixel of each axis to the pixel one past the end, which a vessel reaches at the antimeridian or at a pole. Static and free of game state so the mapping can be tested.
