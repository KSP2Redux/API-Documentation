    Class ShaderRefactorProfile

    Describes how PQSRenderer should drive a given ShaderRefactorState: which shader the planet material uses, the base shader pass offset, and which modern-pipeline features are active. Routing every renderer decision through a profile keeps the per-variant behaviour in one table instead of scattered == Standard checks, so adding a variant is a single enum value plus a single table entry.
