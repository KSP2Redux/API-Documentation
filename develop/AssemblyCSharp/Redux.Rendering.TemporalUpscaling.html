    Class TemporalUpscaling

    Selects URP's temporal upscaler (STP, DLSS or FSR 2) and its render resolution for the whole pipeline.

    Inheritance
    object
    TemporalUpscaling
    Namespace: Redux.Rendering
    Assembly: Ksp2Redux.dll
    Syntax
    public static class TemporalUpscaling
    Remarks

    URP 17.6 has one active upscaler per pipeline, stored by name on the pipeline asset, and per-upscaler options sub-assets in that asset. A temporal upscaler also turns on the camera jitter, the motion vectors and the history that URP's TAA uses. DLSS and FSR 2 pick their render size from a quality mode, STP from the render scale. DLSS and FSR 2 run as ReactiveDlssUpscaler and ReactiveFsr2Upscaler, which add UpscalerReactiveMask's mask over transparents.

    Remarks

    An upscaler the machine cannot run falls back to none, since URP would otherwise jitter the frame and upscale it bilinearly. The selection lives on the pipeline asset, so in the editor it is written to the asset like any other change made to it in play mode.
