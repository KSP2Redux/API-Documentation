    Class MainMenuVesselCreditTracker

    Holds the credit for whichever vessel the main menu rotation currently has on screen.

    Inheritance

    public static class MainMenuVesselCreditTracker
    Remarks

    The rotation and the display are built by different things at different times, and neither owns the other: the rotation is created by the prefab loader, and the display is instantiated by the menu once its panel exists. This sits between them so that whichever arrives second can still catch up, by reading Current rather than only listening for the next change.
