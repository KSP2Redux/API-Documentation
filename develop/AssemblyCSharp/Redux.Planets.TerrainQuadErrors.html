    Class TerrainQuadErrors

    Holds the geometric error of a body's PQS quads by address: how far each quad's mesh strays from the terrain it stands for, in meters.

    Inheritance
    object
    TerrainQuadErrors
    Namespace: Redux.Planets
    Assembly: Assembly-CSharp.dll
    Syntax
    public class TerrainQuadErrors
    Remarks

    Errors are kept nested, so a quad's error is never below a measured descendant's, and a split decided on a parent cannot fight a merge decided on its children. They depend only on the terrain, so they stay valid until Clear(), which a decal change calls. A measurement taken before a clear is dropped when it lands.

    Remarks

    An unmeasured quad takes its nearest measured ancestor's error, a quarter for every level down, as on a surface curving smoothly. It under-refines briefly, and detail fills in once its own measurement lands.
