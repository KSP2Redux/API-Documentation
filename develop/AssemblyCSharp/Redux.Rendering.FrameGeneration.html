    Class FrameGeneration

    Runs NVIDIA DLSS Frame Generation, which shows generated frames between the rendered ones.

    Remarks

    The ReduxStreamline plugin loads with the player, before Unity creates its D3D12 device, and puts NVIDIA Streamline under Unity's present queue and swap chain, so Streamline presents the frames. The editor has no swap chain for it, so frame generation runs only in a player.

    Each frame the player loop takes Streamline's frame token, sleeps in Reflex and marks the simulation, and the render thread marks the frame's submission. On the current scene or map camera the hook copies URP's depth and the motion vectors BodyMotionVectorsPass corrected into textures that nothing else writes before the frame is presented, the right way up for the back buffer, and hands them to Streamline with the camera's matrices. The plugin turns frame generation off for any frame that comes without them, such as a loading screen, so no frame is generated from stale inputs.

    The game's HUD is overlay UI, which URP draws into the back buffer after its final blit. In SDR the plugin copies the back buffer just before that as the HUD-less color, and again once the frame is drawn. Where the two differ is the UI's coverage. With both, Streamline interpolates the UI apart from the scene, so the HUD does not ripple with the motion behind it. Under HDR output the UI is composited in URP's final blit, and the scene and UI are interpolated together.
