    Class BundleConversionRuntime

    Reads a bundle conversion journal and serves the converted stock bundles it describes.

    Inheritance
    object
    BundleConversionRuntime
    Namespace: Redux.Assets
    Assembly: Ksp2Redux.dll
    Syntax
    public static class BundleConversionRuntime
    Remarks

    The launcher converts the stock bundles so materials that embedded their own shader copy point at the URP replacement bundles (ksp2redux.tools, bundles convert). Bundles that allowed it were edited in place, and the rest were rewritten into Redux/BundleConversion/StandaloneWindows64. This class finds that journal from a stock bundle's own path. On first use per install it re-applies in-place edits that a Steam "verify files" put back to stock, using the old and new bytes the journal recorded, and it only hands out a copy while the stock file still has the size it was converted from.

    The editor converts into a cache folder of the project instead (CacheRoot) and never writes to the install. The copies come from the cache, and the bundles the launcher would edit in place are read through a stream that shows the recorded edits over the stock bytes (TryOpenPatched(string, out Stream)).

    Bundles whose cloud cubemaps the converter stored in smaller formats are read through the same stream in the game and the editor alike. Their overlay shows new header bytes and the converted pixels, which come from a data file beside the copies, while the stock file stays as Steam installed it.

    Remarks

    Linked SDK content in a local development player loads the stock bundles it depends on from the game the player was built against (LinkedAddressableRuntime), which this install's conversion never saw, so their materials kept the Built-in shaders and GrabPass errors filled the log. A stock bundle's file name is the same wherever it is, so the install's file of that name is the same bundle.
