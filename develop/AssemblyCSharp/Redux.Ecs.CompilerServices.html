    ModuleConfigBlobRegistry

    Per-Unity.Entities.World content-addressed cache of part-module config blobs. Module config is immutable and identical across instances of a part type, so every instance shares one blob keyed by its content hash. Backed by Unity.Entities.BlobAssetStore, which owns the blobs and disposes them all when the world tears down (via ModuleConfigCleanupSystem).

    BlobFloatCurve

    A FloatCurve baked into a blob-resident lookup table so it can be evaluated from Burst. Mirrors FloatCurveStruct: the curve is pre-sampled into a fixed-size table over [0, MaxTime].

    ModuleConfigCleanupSystem

    Disposes this world's ModuleConfigBlobRegistry when the world tears down. The system does no per-frame work; it exists only so its OnDestroy(ref SystemState) runs.

    ModuleConfigHasher

    Accumulates a content hash over a module config's source values so identical configs resolve to the same shared blob in ModuleConfigBlobRegistry. Codegen feeds every blob-bound field through the matching Add overload.
