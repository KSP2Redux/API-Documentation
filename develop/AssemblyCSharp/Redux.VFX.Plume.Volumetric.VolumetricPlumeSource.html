    Class VolumetricPlumeSource

    Supplies engine state and nozzle transforms to the shared volumetric exhaust renderer.

    Inheritance
    object
    VolumetricPlumeSource
    Implements
    IEngineFXData
    IEngineFXDataModeHint
    Namespace: Redux.VFX.Plume.Volumetric
    Assembly: Assembly-CSharp.dll
    Syntax
    public class VolumetricPlumeSource : MonoBehaviour, IEngineFXData, IEngineFXDataModeHint
    Remarks

    In flight the engine effects manager attaches this component, or reuses one authored on the part prefab or added by a prefab patch. In the editor it takes part in the engine effects preview of its ThrottleVFXManager, so the preview throttle and atmosphere controls drive the exhaust live.
