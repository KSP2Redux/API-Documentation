    Class VesselMissionProgressTransfer

    The rules for moving per-vessel mission progress between vessels, and for deciding which vessels may hold it.

    Inheritance
    object
    VesselMissionProgressTransfer
    Namespace: Redux.Missions
    Assembly: Assembly-CSharp.dll
    Syntax
    public static class VesselMissionProgressTransfer
    Remarks

    Mirrors how science moves: joining two vessels merges their progress, splitting one gives both halves a copy, and nothing is ever partitioned or lost. Kept apart from the component so the rules can be tested without a simulation to hang them on.

    Returns

    The stamp for the joined vessel.
    Remarks

    Joining mints a new vessel, so the stamp has to be inherited rather than taken from the clock, or docking anything to an old station would present the station as newly built. The later of the two is taken, which matches the permissive rule the rest of these transfers use.

    bool requiresNewVessel

    Whether the mission asks for a craft built after it was picked up.
    Returns
    Type Description
    bool

    True if the vessel may hold progress for the mission, false otherwise.
    Remarks

    Every vessel qualifies unless the mission asks otherwise, which is how KSP1 contracts treat craft that already exist. When it does ask, a vessel qualifies only if it was built after the mission was picked up. That comparison is strictly later on purpose: a save written before either stamp existed has both at zero, and reading equal as eligible would waive the requirement on every campaign that predates this.

    VesselMissionRecord second

    The other vessel's record. May be null.
    Returns
    Type Description
    VesselMissionRecord

    The merged record, or null when neither side holds one.
    Remarks

    The record that reached the later stage wins, and its variables and latches come with it, since they describe the stage it is on rather than the one the other vessel is on. Completed stages are unioned, because a stage either vessel finished is finished for the craft they became.
