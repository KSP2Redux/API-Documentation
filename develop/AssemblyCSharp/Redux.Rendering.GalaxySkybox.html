    Class GalaxySkybox

    Draws the skybox the active galaxy declares wherever the stock game draws its galaxy cubemap.

    Inheritance
    object
    GalaxySkybox
    Namespace: Redux.Rendering
    Assembly: Ksp2Redux.dll
    Syntax
    public static class GalaxySkybox
    Remarks

    The stock cubemap is referenced by several bundled materials, among them the flight and KSC sky, the map camera's copy and the main menu's sky camera, and they load at different times. Rather than finding them up front, each camera's sky is checked as the camera begins rendering and moved onto the active cubemap if it still shows the stock one. The reflection cubemap and the global cubemap the scaled shaders sample are moved the same way. Materials moved once are kept, so a later galaxy moves them all at once.
