    Class ReduxBloom

    The Post Processing Stack v2 bloom, rendered in place of URP's bloom on cameras with a package layer.

    Remarks

    The parameters, their defaults and their blending are the package's, so the converted volumes blend exactly as the package blended the originals. A parameter that a volume does not override keeps the value of the volumes below it, which is how Mission Control's bloom gets the flight volume's diffusion and anamorphic ratio. Redux.Rendering.PostProcessing.BloomHook renders the blended result. PostProcessingBridge fills it from the stock profiles.
