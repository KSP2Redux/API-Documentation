    Struct PmScope

    A mod-scoped fluent patch context carrying the mod ID.

    Namespace: PatchManager.CSharpPatching
    Assembly: Ksp2Redux.dll
    Syntax
    public readonly struct PmScope
    Remarks

    Domain-specific patch methods (PatchPart, PatchPlanet, ...) are extension methods on this type, so any domain or mod can add its own.
