    Struct PatchBuilder<T>

    A type-safe fluent wrapper over a queued PatchDefinition.

    Namespace: PatchManager.CSharpPatching
    Assembly: Assembly-CSharp.dll
    Syntax
    public readonly struct PatchBuilder<T>
    Type Parameters
    Name Description
    T

    The asset wrapper type the patch's converter produces.
    Remarks

    T is the asset wrapper the patch's converter produces, for example PartUserData, so Do(Action<T>) and Requires(Func<T, bool>, string) take that type with no cast and no chance of a wrong-type lambda.
