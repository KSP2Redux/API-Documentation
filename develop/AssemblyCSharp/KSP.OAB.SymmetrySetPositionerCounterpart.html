    Class SymmetrySetPositionerCounterpart

    Positions the second ends of a compound part set, such as struts, from where the first ends of a mirror set sit.

    Inheritance
    object
    SymmetrySetPositionerCounterpart
    Implements

    Namespace: KSP.OAB
    Assembly: Ksp2Redux.dll
    Syntax
    public class SymmetrySetPositionerCounterpart : ISymmetrySetPositioner
    Remarks

    The first ends mirror across a plane of the part they are attached to and are carried to each part of that part's radial set. The second ends are attached to some other part, whose own mirror plane is not the same, so each second end takes the transform that carries the anchor first end to its own first end instead.

    Remarks

    The positioner knows the first ends only for the second end it was made for, and for the copies the placement made. It cannot pose a set from another anchor, or a set that lost a part, so the other parts stay where they are then.
