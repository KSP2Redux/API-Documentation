    Struct PatchedConicsOrbitData

    Unmanaged Keplerian state for a patched-conics orbit: the orbital elements plus the values derived from them during propagation. PatchedConicsOrbit holds one of these and forwards its public API to it; the Keplerian math is (being) moved onto this struct as instance methods so it can later run in a Burst job.

    Namespace: Redux.Ecs.Components
    Assembly: Assembly-CSharp.dll
    Syntax
    public struct PatchedConicsOrbitData
    Remarks

    All fields are blittable value types (the same ones already used inside Burst code such as Transformd and the n-body OdeSolveJob). Managed/coordinate-system-bound state (reference body, Vector velocity, patch graph, delegates) stays on the wrapper. The external Z-up frame is threaded into the math as a parameter.
