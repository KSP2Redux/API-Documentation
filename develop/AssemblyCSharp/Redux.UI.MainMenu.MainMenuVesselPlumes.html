    Class MainMenuVesselPlumes

    Whether a menu craft's engines are firing.

    Inheritance
    object
    MainMenuVesselPlumes
    Namespace: Redux.UI.MainMenu
    Assembly: Assembly-CSharp.dll
    Syntax
    public static class MainMenuVesselPlumes
    Remarks

    A craft is built with its effects however the parts shipped them, which for an engine is running. Nothing switches them off, because what normally would is the engine module, and a menu craft has no modules: a craft parked in front of the camera sits there under full thrust going nowhere. It fires on its way out and at no other time.
