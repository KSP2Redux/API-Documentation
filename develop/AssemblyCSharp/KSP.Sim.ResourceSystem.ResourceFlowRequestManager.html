    Class ResourceFlowRequestManager

    Manages resource flow requests for a part owner, coordinating request registration, prioritization, and delivery via a flow graph. Each request is its own ECS entity (the entity is the request's identity); this manager creates, drives, and tears those entities down and runs the managed delivery solve over them. Request inputs live in each entity's ResourceFlowInstructionData buffer and outputs in its ResourceFlowResponse (+ ResourceFlowFailedResource buffer).
