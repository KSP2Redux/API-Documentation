    Class CrtVignetteEffect

    The KSP CRT vignette: a vignette with CRT subpixels and rolling scanlines, drawn after URP post-processing.

    Inheritance
    object
    VolumeComponent
    CrtVignetteEffect

    Assembly: Ksp2Redux.dll
    Syntax
    [VolumeComponentMenu("Redux/KSP CRT Vignette")]
public sealed class CrtVignetteEffect : VolumeComponent
    Remarks

    The URP counterpart of the stock CRTVignette Post Processing Stack v2 effect, which the package injected after its built-in stack. Redux.Rendering.PostProcessing.CrtVignetteHook renders it with the ported Hidden/KSP/CRTVignette shader. The parameters and defaults are the stock effect's.
