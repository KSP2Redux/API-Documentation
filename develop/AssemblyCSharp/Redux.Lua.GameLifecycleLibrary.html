    Class GameLifecycleLibrary

    The Lua Game global through which mod scripts register live-game lifecycle closures.

    Inheritance
    object
    GameLifecycleLibrary
    Namespace: Redux.Lua
    Assembly: Assembly-CSharp.dll
    Syntax
    [MoonSharpUserData]
public sealed class GameLifecycleLibrary
    Remarks

    Methods mirror the phases GameLifecycleManager drives: the generic Game:Update(fn), Game:FixedUpdate(fn), Game:SceneEnter(fn), Game:SceneExit(fn), the named scene wrappers (Game:OnFlight(fn) and friends, which fire only on their own state with no argument), and Game:OnActiveVesselChanged(fn) (fires with the new active vessel). The generic scene callbacks receive the state as a GameState value, comparable against the named members of the GameState global table (for example GameState.FlightView). Stateless: the calling mod is read from the script context, so one shared instance serves every mod environment.
