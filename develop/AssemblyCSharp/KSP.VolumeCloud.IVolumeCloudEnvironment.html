    Interface IVolumeCloudEnvironment

    The scene state a VolumeCloudRenderer reads each frame: lights, the body, its atmosphere, ocean depth, time and the floating origin.

    Namespace: KSP.VolumeCloud
    Assembly: Assembly-CSharp.dll
    Syntax
    public interface IVolumeCloudEnvironment
    Remarks

    The game and previs scenes supply it from their GraphicsManager. The SDK planet preview has none and supplies its own.
