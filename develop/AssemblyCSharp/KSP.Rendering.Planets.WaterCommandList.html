    Class WaterCommandList

    A list of rendering commands that the water systems record during late update and a camera render hook replays.

    Inheritance
    object
    WaterCommandList
    Namespace: KSP.Rendering.Planets
    Assembly: Ksp2Redux.dll
    Syntax
    public class WaterCommandList
    Remarks

    The Built-in pipeline let the water code fill a CommandBuffer that ran at a camera event. A URP render graph pass records into a command buffer of its own, which cannot execute another one, so the commands are kept here and written into the pass's buffer by Replay(CommandBuffer). The methods mirror the CommandBuffer overloads the water code uses. Values and vector arrays are copied at record time. Materials, property blocks, buffers and textures are referenced and read when the list is replayed.
