    Class ReduxSurfaceSpawner

    Spawns an addressable prefab at a fixed lat/lon/altitude on the parent celestial body, gated by proximity to the active vessel.

    Remarks

    The instance's world pose is recomputed each frame in Redux.CelestialBody.ReduxSurfaceSpawner.LateUpdate. The authored lat/lon/altitude and the surface radius sampled once at spawn give a body-local position and rotation in double precision, which the active IPhysicsSpaceProvider converts into Unity physics space. That conversion applies the floating-origin offset, so it is the only correct way to reach world space - walking the body transform hierarchy would miss it. All math happens in Vector3d / QuaternionD, and the only precision loss is the final implicit cast to Vector3 near the floating origin where float precision is centimeter-scale.

    The addressable handle is released as soon as the prefab is instantiated. The instance is a runtime copy that survives the release. Subsequent spawn cycles re-load the addressable - the trade-off is more I/O on respawn for less memory held while no instance is active.
