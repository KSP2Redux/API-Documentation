    Class MotionVectorDebugPass

    Debug views of URP's motion vectors on the flight camera, drawn over the colour before post-processing.

    Inheritance
    object
    MotionVectorDebugPass
    Implements
    ICameraRenderHook
    Namespace: Redux.Rendering
    Assembly: Ksp2Redux.dll
    Syntax
    public sealed class MotionVectorDebugPass : ICameraRenderHook
    Remarks

    The reprojection error view compares this frame's colour with last frame's, fetched where the motion vector says each pixel was. Surfaces whose motion is right go dark, so it checks object motion, the body motion of terrain and the history the temporal SSR pass and temporal upscalers build on.
