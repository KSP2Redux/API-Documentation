    Class ResourceFlowRequestBroker

    Mediates resource flow request allocation and lifecycle for a single IFlowNode through a ResourceFlowRequestManager. A request is identified by its ECS Unity.Entities.Entity, which the caller stores and passes back. There is no handle and no string identifier.
