    Class MainMenuWorkspaceVesselBuilder

    Builds a display-only vessel from a saved workspace file, for the main menu to rotate through. Parts are instantiated and dressed to look right and nothing more, since none of this is simulated.

    The authored name, which is the material's own name when the menu has not touched it.
    Remarks

    A part is dressed for the menu before anything reads its materials back, so by then every name carries the builder's own prefix and may carry Unity's instancing suffix as well. What a part's authoring names is neither of those, so a comparison against it has to be made on the name underneath.
