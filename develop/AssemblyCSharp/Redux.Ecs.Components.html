    Namespace Redux.Ecs.Components

    Classes

    CurrentPatchedConicsOrbit

    Managed ECS component representing the current patched-conics orbit patch for an entity. Unmanaged orbital data is read from and written to the entity's PatchedConicsOrbitData component; managed-side state (velocity, patch graph) is stored directly on this class. The reference body is identified by ReferenceBodyEntity and resolved to a CelestialBodyComponent on demand via SimObjectManagedData.

    ModuleManagedData

    Managed back-reference from a module entity to its ModuleData entries, letting ModuleEntities unbind the managed side before the entity is destroyed.

    OabAssemblyManagedData

    Managed back-reference from an editor assembly entity to its ObjectAssembly.

    OabPartManagedData

    Managed back-reference from an editor part entity to its ObjectAssemblyPart.

    PartMembership

    Stamps and strips the part-owner membership component set (PartVessel, PartOwnerRef, and the PartParent/PartChild attachment-tree placeholders) on a part entity, shared by flight (PartOwnerComponent) and the editor (ObjectAssembly).

    ResourceRequestEntity

    Creates and tears down resource-flow request entities and toggles their active flag. A request entity is the sole identity of a request: it carries RequestVessel (shared, the solve filter), RequestPart, a ResourceFlowRequest header, its own ResourceFlowInstructionData buffer, a ResourceFlowResponse, and a ResourceFlowFailedResource buffer.

    ResourceRequestIndex

    Reserved values for Index. The index is a caller-defined discriminator, never an identity or dedup key.

    SimObjectManagedData

    Structs

    AncestorList

    A list of ancestor entities (entity.parent.parent.parent... etc) starting with, and including the current entity. This is backward from the way this is normally handled, but allowed constructing the list from leaf to root without reversing.

    AngularVelocityD

    Unmanaged equivalent of AngularVelocity: a relative angular velocity (itself a frame-bound VectorD) plus the entity whose motion frame it is relative to.

    BoundViewObject

    CelestialBodyChild

    One orbiting child of a celestial body. Each body holds a buffer of its children; the CelestialBodyHierarchyRoot singleton holds the stars.

    CelestialBodyHasRotationUpdate

    Marks that a body's rotation changed this tick. The celestial-body ordered update owns the flag: it clears it at the start of each update and re-enables it only when it recomputes the rotation. The legacy fixed update reads it to raise CelestialBodyComponent.RotationUpdated and CelestialBodyComponent.AngularVelocityUpdated.

    CelestialBodyHierarchyRoot

    Singleton root of the celestial-body tree; its CelestialBodyChild buffer holds the stars.

    CelestialBodySimData

    Unmanaged source of truth for the celestial-body fields driven by CelestialBodyOrderedUpdateSystem, exposed as accessor properties on CelestialBodyComponent.

    ContainerOwner

    Links a resource-container entity to the part entity that owns it.

    CoolerRequiredResource

    One resource a cooler consumes while operating (rate and acceptance threshold), stamped onto the cooler module entity from the managed required-resource settings with names resolved to runtime ids.

    CoolingEnergyToApply

    MassModifierData

    Per-module mass contribution, written on a module entity by its part-module system and scattered into the owning part's PartMassModifier by MassAggregateSystem.

    ModulePart

    The part entity that a part-module entity belongs to. A module instance lives on its own entity and resolves its owning part's data through this back-reference.

    ModuleRequestEntity

    The resource-flow request entity owned by a part-module entity. Backs RequestEntity; added when the module first allocates a request.

    OrbitStabilityData

    Tracks whether a vessel's patched-conics orbit is currently stable, so OrbitStabilitySystem can emit an event on the unstable-to-stable edge.

    OrbiterData

    Authoritative unmanaged state for OrbiterComponent.

    OrbiterFrame

    The orbiter's own celestial frame entity; its Transformd holds the live (physics-driven) position the orbit-driver job resolves the owning body from when the orbiter is off-rails.

    OrbiterMainBody

    The body whose SOI owns this orbiter, resolved each tick by the orbit-driver job. Unity.Entities.Entity.Null when unresolved this tick: a celestial body, no reference body, or the job has not run yet.

    OverheatEvent

    Emitted by the thermal finalize job when a part's temperature exceeds its maximum, so a later managed system can destroy it without the Burst pipeline taking a sync point.

    PartChild

    One attachment-tree child of a part within its part owner, as an entity reference. The buffer on a part entity holds all of its children. Rebuilt by UpdatePartRelationships().

    PartComponentData

    Unmanaged source of truth for the blittable state of a part, exposed as accessor properties on PartComponent.

    PartMassModifier

    A per-part component that is used by the mass update to sum up all mass modifiers on the part.

    PartModuleRef

    One part-module entity owned by a part, as an entity reference. The buffer on a part entity holds every module instance mounted on that part. Maintained by ModuleEntities as modules are bound and removed.

    PartOwnerData

    Unmanaged source of truth for the plain (blittable) state of a part owner, exposed as accessor properties on PartOwnerComponent.

    PartOwnerRef

    The part owner entity a part belongs to (Unity.Entities.Entity.Null when unowned). Maintained alongside the part's PartVessel shared component as parts are added to and removed from owners.

    PartParent

    The attachment-tree parent of a part within its part owner, as an entity reference (Unity.Entities.Entity.Null for the root or a part with no parent). Rebuilt by UpdatePartRelationships().

    PartVessel

    The part-owner (vessel) entity that a part belongs to, as a shared component so that all parts of a single vessel are grouped into the same chunks. This lets a query filter a vessel's parts with SetSharedComponentFilter and reduce a per-part component across the whole vessel without walking managed state. Stamped and stripped alongside the PartOwnerComponent membership buffer.

    PatchedConicsOrbitData

    Unmanaged Keplerian state for a patched-conics orbit: the orbital elements plus the values derived from them during propagation. PatchedConicsOrbit holds one of these and forwards its public API to it; the Keplerian math is (being) moved onto this struct as instance methods so it can later run in a Burst job.

    PhysicsSpaceFrame

    Singleton exposing the inertial reference frame entity (the PhysX/floating-origin frame) to Burst jobs, so they can perform the velocity/angular conversions otherwise only available on the managed PhysicsSpace provider.

    PhysicsStatsDirty

    Enableable tag on part-owner and part entities: enabled means the owner's physics stats need recomputing. Set on the owner by PartOwnerComponent (per-frame in OnLateUpdate, on structural changes, and by the forced recalculation path), broadcast onto the owner's parts by BroadcastDirtyFlagSystem, and cleared once the physics reduce has recomputed the owner. The part-level and owner-level reduce jobs filter on it, so clean owners are skipped entirely.

    PositionD

    Unmanaged equivalent of Position: a position value plus the transform-frame entity it is expressed in.

    RequestPart

    The part entity a resource-flow request flows against. Doubles as the plan-lookup flow target.

    RequestVessel

    The part-owner (vessel) entity that a resource-flow request belongs to, as a shared component so all of a vessel's request entities are grouped into the same chunks. The solve filters a vessel's requests with SetSharedComponentFilter. Derived from the request's RequestPart's PartVessel and reconciled when the part changes owner (docking, re-parent).

    ResourceDefinitionRow

    An unmanaged mirror of ResourceDefinitionData.

    ResourceDefinitionsCacheTag

    Tag identifying the singleton entity that carries the baked resource definition buffers (ResourceDefinitionRow and ResourceIngredientRow).

    ResourceFlowFailedResource

    One resource a request failed to process this tick. Populated only on rejection; cleared before each solve.

    ResourceFlowInstructionData

    One compiled flow instruction on a request entity. The buffer holds exactly this request's instructions — one buffer is one request, so there are no slice fields. The flow target is not stored here; it is the request's RequestPart.

    ResourceFlowRequest

    Header for a resource-flow request entity: a control flag plus a non-identity discriminator. The request's instructions live in its own ResourceFlowInstructionData buffer and the entity is the identity, so there is no handle and no buffer slice.

    ResourceFlowResponse

    Output of the solve for a request entity. Rejected resources are recorded in the ResourceFlowFailedResource buffer.

    ResourceIngredientRow

    One recipe ingredient: the resource moved per unit of the recipe resource. Referenced by ResourceDefinitionRow ingredient slices.

    ResourceStoredEntry

    One per-resource storage slot of a ResourceContainer.

    RigidbodyData

    Unmanaged source of truth for the blittable state of a rigidbody, exposed as accessor properties on RigidbodyComponent.

    RotationD

    Unmanaged equivalent of Rotation: a local rotation value plus the transform-frame entity it is expressed in.

    SimObjectData

    Unmanaged type flags for a SimulationObjectModel, packed into a single bitset and exposed as boolean accessors.

    TelemetryData

    Unmanaged source of truth for the plain flight-telemetry state of a simulation object, exposed as accessor properties on TelemetryComponent.

    ThermalBodyContext

    Per-owner body chain (main body up through its reference bodies); each entry is a body and its surface-flux base.

    ThermalOwnerData

    Per-vessel thermal aggregates on the part owner entity: the sum of per-part cooling demand, the vessel's total cooling budget from its operational coolers, and the main body's atmospheric temperature at the vessel's altitude.

    TransformChild

    The transform entities parented to this entity - the downward half of the hierarchy whose upward half is Unity.Transforms.Parent and AncestorList.

    Transformd

    Struct representing ECS transform data.

    UniverseRotationState

    Singleton holding the universe-wide inverse-rotation frame state.

    VectorD

    Unmanaged equivalent of Vector: a vector value plus the transform-frame entity it is expressed in.

    VelocityD

    Unmanaged equivalent of Velocity: a relative velocity (itself a frame-bound VectorD) plus the entity whose motion frame it is relative to.

    VesselData

    Unmanaged source of truth for a vessel's physics mode and per-tick derived dynamics, aero, and attitude scalars, exposed as accessor properties on VesselComponent.

    VesselRoot

    Indicates which part is the root part of the vessel.
