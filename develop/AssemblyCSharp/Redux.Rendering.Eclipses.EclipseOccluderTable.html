    Class EclipseOccluderTable

    The star and the bodies that can eclipse it, uploaded once per frame in scaled space for KSP2Eclipse.hlsl, and the occluders of each scaled body.

    Inheritance
    object
    EclipseOccluderTable

    Assembly: Ksp2Redux.dll
    Syntax
    public static class EclipseOccluderTable
    Remarks

    A scaled body is eclipsed by its parent unless the parent is a star, by its siblings when the parent is not a star, and by its own moons (URP/notes/eclipses.md, section 3.2). Never by itself, which its own lighting already shades. Positions come from the simulation through the scaled-space frame, as ScaledPlanetaryBodyView places the bodies, so the table does not depend on which of them updated first. While the map is open the map camera draws from a second table in map space (UploadMap(Map3DView, CelestialBodyComponent, IReadOnlyList<CelestialBodyComponent>)).

    CelestialBodyComponent star

    The bodies that can hide the star from the observer, the observer's own body included. Stars are left out, and bodies past MAX_LOCAL_OCCLUDERS.
    Remarks

    The table only reaches the camera that draws the local scene, and only in a frame it was uploaded for. Every other camera (map, menus, portraits) sees an empty table, so one left over from flight, which is in physics space, never darkens them. The observer's own body goes first in the table, where the shaders tell its night, which the local sun carries as in stock, from the other bodies' eclipses, which the sun does not carry and each pixel takes in full.

    UploadMap(Map3DView, CelestialBodyComponent, IReadOnlyList<CelestialBodyComponent>)

    Builds the table in map space for the map camera: the star and the bodies where the map draws them, at the size it draws them, the ring nearest the map camera, and the occluders of each body the map draws.

    Declaration
    public static void UploadMap(Map3DView mapView, CelestialBodyComponent star, IReadOnlyList<CelestialBodyComponent> bodies)
    Parameters
    Type Name Description
    Map3DView mapView

    The map view whose bodies are drawn.
    CelestialBodyComponent star

    The star whose light the bodies block.
    IReadOnlyList<CelestialBodyComponent> bodies

    Every celestial body. Stars are left out, and bodies past the table size too.
    Remarks

    The map lights every body from the star's map position (CelestialBodyMapLighting), so around the focus the map table's shadows fall where its light does. Only the map camera reads it, through the table hook, and every other camera keeps the scaled table. The bodies take the same order as in Upload(IScaledSpaceFrame, CelestialBodyComponent, IReadOnlyList<CelestialBodyComponent>), so a receiver's indices hold in both tables.
