    Class MessageInfo

    Optional editor-and-author-facing metadata for a MessageCenterMessage subclass.

public class MessageInfo : Attribute
    Remarks

    Decorating a message with this attribute lets the mission editor render it correctly in the EventCondition picker and row UI. All fields are optional and fall back to safe defaults when absent, so existing messages compile unchanged.

    Category

    Shared picker bucket. Many messages may share the same Category (for example "Vehicle", "Game", "Part"). Free-form string. The picker groups by Category and falls back to "Uncategorized" when null.

    InputFilterHint

    Author-facing label for the message's InputStringList filter on the EventCondition row (for example "resource name", "celestial body name"). Null hides the input filter field entirely, signalling that filtering this message type by InputString is not meaningful because the publisher does not populate the list.
