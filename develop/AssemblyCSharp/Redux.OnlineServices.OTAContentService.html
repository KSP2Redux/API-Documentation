    Class OTAContentService

    Entry point for Redux's over-the-air content: first-party localization, mission, and main-menu vessel updates fetched from the content repository. This class only orchestrates - the loading flow calls into it, and it delegates config, downloading, applying, and the consent dialog to the focused types in this namespace.

    Action<string> reject

    Called with the failure text if the handover throws.
    Remarks

    The caller does not wait on this. The menu opens on what is already in the scene and changes to a published craft once one has been built, so a slow build delays the first change rather than the menu.
