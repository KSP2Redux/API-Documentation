    The stage identifiers the furthest along craft has finished, or null when none has any.
    Remarks

    For Mission Control, which shows how far the fleet has got. The live mission holds whichever craft is flying, so reading it there would report an arbitrary one of several craft working the same run. This answers the question rather than writing the answer onto the mission everything else evaluates from.

    ReconcileOnLoad(GameInstance)

    Settles per-vessel progress once a campaign has finished loading.

    Declaration
    public static void ReconcileOnLoad(GameInstance game)
    Parameters
    Type Name Description
    GameInstance game

    The running game.
    Remarks

    Two jobs. Progress that no longer describes anything is dropped: a save taken before a mission was finished leaves records on craft still in flight, and they would resurface as progress on something already sitting in the completed list, and the same sweep covers records for missions that no longer exist, which is what a definition withdrawn from downloaded content leaves behind. What survives is then handed to the mission for whichever craft the player is about to fly.

    Tick(GameInstance, MissionData)

    Advances a mission by one tick, keeping the active vessel's progress in step with it.

    Declaration
    public static void Tick(GameInstance game, MissionData missionData)
    Parameters
    Type Name Description
    GameInstance game

    The running game.
    MissionData missionData

    The mission to advance.
    Remarks

    Replaces a bare call to Update(). A mission on a vessel scoped stage does not tick at all while no vessel is active, so progress made at the space centre cannot be credited to nobody, and its progress is written back to the active vessel after every tick so switching craft needs no separate capture. A tick that carries the mission out of its run collapses the run instead.
