    The layer of the copy kept so far.
    Returns
    Type Description
    bool

    True if the offered copy replaces the one kept so far, false otherwise.
    Remarks

    A copy from a later layer in the list wins and a copy from a layer outside the list is never kept, so a layer only has to copy the data it changes. Of several copies in the same layer, the last one offered wins.
