    SetAvailableResources(bool)

    Shows or hides the resource list and the overlay button, and recomputes whether the section is worth showing at all.

    Declaration
    public void SetAvailableResources(bool anyResourceScanned)
    Parameters
    Type Name Description
    bool anyResourceScanned

    Whether the player has scanned anything on the selected body.
    Remarks

    A body whose resources are all still unknown lists nothing, the same way the resource gathering window hides its own table until the first scan lands, and offers no overlay either since there is no map the player has earned the right to see. The section itself survives on its blurb alone. Called again whenever a scan changes what is known, so a scan finishing under an open panel reveals the list rather than waiting for the player to reselect the body.
