    Class MainMenuVesselLights

    Turns a menu craft's own lights on, for the bodies where the sun is not enough to see it by.

    Inheritance
    object
    MainMenuVesselLights
    Namespace: Redux.UI.MainMenu
    Assembly: Assembly-CSharp.dll
    Syntax
    public static class MainMenuVesselLights
    Remarks

    This happens in two halves, because a menu craft has no vessel behind it and the builder destroys every part module as soon as it has read their state. What each part lights up is written down while its modules are still there, and switched later off that record rather than off the modules, which by then are gone.
