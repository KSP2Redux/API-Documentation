    Interface IVSwiftUI

    Interface for the V-SwiFT module-side UI surface, forwarding to the host's UI stack.

    Namespace: VSwift.Modules.UI
    Assembly: Ksp2Redux.dll
    Syntax
    public interface IVSwiftUI
    Remarks

    Implementations are wired up by the V-SwiFT plugin host (see UI.VSwiftUI) so the modules assembly does not need to reference the host UI stack directly.
