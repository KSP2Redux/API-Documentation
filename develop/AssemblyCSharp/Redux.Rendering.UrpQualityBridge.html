    Class UrpQualityBridge

    Applies the game's QualitySettings shadow settings to a session copy of the URP asset.

    Inheritance
    object
    UrpQualityBridge
    Namespace: Redux.Rendering
    Assembly: Ksp2Redux.dll
    Syntax
    public static class UrpQualityBridge
    Remarks

    The game's settings menus, saved profiles and the directional shadow controller still write QualitySettings, which URP ignores. At startup this installs a copy of the project's URP asset as the active quality level's pipeline, so runtime changes never touch the project asset, and before every camera renders it copies shadow distance, cascades and resolution into that copy. Cameras can override the shadow distance and cascade count through SetCameraOverride(Camera, float, int, int).
