    Class CRTVignette

    PostProcessEffectSettings definition for the KSP/CRT Vignette post-process effect, configuring vignette shape, CRT subpixel rendering, and scanlines.

    Inheritance
    object
    PostProcessEffectSettings
    CRTVignette
    Namespace: GlobalKsp2Redux
    Assembly: Ksp2Redux.dll
    Syntax
    public sealed class CRTVignette : PostProcessEffectSettings
    Remarks

    Stock post-processing profiles serialize these settings, so the class keeps its Post Processing Stack v2 layout. Redux converts it to CrtVignetteEffect, which renders after URP post-processing as the package's after-stack effect did.
