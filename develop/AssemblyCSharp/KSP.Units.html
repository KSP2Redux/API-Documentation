    PrintSI(double, string, int, bool, bool, bool, bool, int)

    Returns a formatted string representing the given amount with an appropriate SI prefix and unit symbol.

    Declaration
    public static string PrintSI(double amount, string unitName, int significantFigures = 3, bool longPrefix = false, bool fullUnitName = false, bool showPrefix = true, bool useFixedExponent = false, int fixedExponent = 0)
    Parameters
    Type Name Description
    double amount

    The numeric value to format.
    string unitName

    The localization key identifying the unit to display.
    int significantFigures

    The number of significant figures to use in the formatted output.
    bool longPrefix

    When true, uses the full SI prefix name instead of the abbreviation.
    bool fullUnitName

    When true, uses the full localized unit text instead of the symbol.
    bool showPrefix

    When true, includes the SI prefix in the output.
    bool useFixedExponent

    When true, forces the SI prefix selection to use fixedExponent instead of deriving it from the value.
    int fixedExponent

    The base-10 exponent to use when useFixedExponent is true.
    Returns
    Type Description
    string

    A formatted string combining the scaled numeric value, SI prefix, and unit.
