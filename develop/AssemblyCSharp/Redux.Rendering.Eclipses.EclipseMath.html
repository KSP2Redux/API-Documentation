    double starRadius

    The physical star radius.
    Vector3d occluderCenter

    The occluder centre position.
    double occluderRadius

    The physical occluder radius.
    Returns
    Type Description
    double

    The exact single-occluder covered fraction in [0, 1], or zero for a rejected occluder.
    Remarks

    All positions and physical radii use the same units and coordinate frame. A point on or inside the occluder uses a pi / 2 angular radius for the local horizon. At the occluder centre, where its direction is undefined, the discs are treated as centred. A point at the star centre has no viewing direction and returns zero coverage.

    Parameters
    Type Name Description
    Vector3d point

    The viewing position.
    Vector3d starCenter

    The star centre position in the same frame as the viewing position.
    double starRadius

    The star radius in the same units as the positions.
    IReadOnlyList<Vector3d> occluderCenters

    The occluder centre positions in the same coordinate frame.
    IReadOnlyList<double> occluderRadii

    The occluder radii in the same units as the positions.
    Returns
    Type Description
    double

    The visible fraction in [0, 1], or one when no occluder covers the star.
    Remarks

    The lists must be non-null and have matching lengths, with corresponding centres and radii. The product is exact for one occluder and approximates multiple occluders. Disjoint covered fractions add geometrically, so their product leaves slightly too much light. Occluders covering the same part of the disc can make the product too dark.
