    Remarks

    The sphere this object sits on can be parked across a universe reset and reattached to a new body view, while the body, the simulation frame the transform model hung from and the surface proxy that held the object are all destroyed with the old universe. The transform model is rebuilt rather than re-parented, since re-parenting converts through the dead frame. The cached body-relative placement is reused, so the object is not positioned a second time.
