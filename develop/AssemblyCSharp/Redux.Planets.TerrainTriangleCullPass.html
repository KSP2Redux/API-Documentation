    Class TerrainTriangleCullPass

    Culls a body's visible PQS triangles and buckets the survivors for the biome passes, in place of the stock QuadMeshTriangleCulling, CalculateMeshBiomeBucketingArgs and MeshBiomeTriplanarBucketing kernels.

    Inheritance

    Assembly: Assembly-CSharp.dll

    public class TerrainTriangleCullPass
    Remarks

    The stock kernels index triangles by thread group X alone, and a dispatch past 65535 groups is refused, which left a body with more than 16383 visible quads drawing no terrain at all. These kernels do the same per-triangle work with their groups spread over X and Y. Every input is bound on each call, so one shader serves every body.
