    Class MainMenuRotationTuning

    How long a craft takes to leave and to arrive, and a way to watch it happen on demand.

    Inheritance
    object
    MainMenuRotationTuning
    Namespace: Redux.UI.MainMenu
    Assembly: Assembly-CSharp.dll
    Syntax
    public static class MainMenuRotationTuning
    Remarks

    These are settled by eye rather than by argument, and the only way to judge a value is to see a craft move at it. Waiting out the half minute a craft stays up between changes, restarting the game to try the next number, is most of the cost of picking one, so the numbers are reachable while the menu is up and a change can be asked for at any moment:

    Ksp2Redux.Cli.exe eval csharp "Redux.UI.MainMenu.MainMenuRotationTuning.RotateNow(3f, 1.5f)"

    What is set here stays set until Reset() or the game is restarted, so the same timing can be watched several times over. The length of the planet turn is not here: it belongs to a setting players can reach, and is read from that setting every time a turn begins.

    DEFAULT_LIGHT_SCALE_EXPONENT

    How a craft's own lights are brightened for the size it is drawn at, as a power of that size.

    Declaration
    public const float DEFAULT_LIGHT_SCALE_EXPONENT = 0.4
    Field Value
    Type Description
    float
    Remarks

    Two is what the light physically loses and reads as a floodlit toy. The sun is scaled at eight tenths, which is that square seen through the eye's own curve. A lamp is looked at directly rather than by what it lights, so it wants less again, and how much less is a matter of taste rather than arithmetic.
