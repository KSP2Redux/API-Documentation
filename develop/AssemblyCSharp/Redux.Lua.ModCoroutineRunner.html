    StopAll()

    Drops every active coroutine. Called at each Play Mode boot so coroutines started by a previous session's scripts do not keep ticking after a play→stop→play cycle when Domain Reload is disabled (this static list otherwise persists, leaving stale handles bound to a dead Script). The driver GameObject is left alone: it is destroyed on play exit and Redux.Lua.ModCoroutineRunner.EnsureDriver recreates it.

    Declaration

    Tick()

    Resumes every coroutine that was active at the start of the frame, dropping the ones that finished, stopped, or threw.

    Declaration
    public static void Tick()
    Remarks

    Each resume is isolated so one faulting coroutine does not stop the rest.
