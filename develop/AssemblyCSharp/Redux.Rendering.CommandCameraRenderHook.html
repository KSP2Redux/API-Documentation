    Class CommandCameraRenderHook

    A camera render hook that records ordinary CommandBuffer commands against the camera targets.

    Inheritance
    object
    CommandCameraRenderHook
    PostAtmosphereRenderHook
    Implements
    ICameraRenderHook
    Namespace: Redux.Rendering
    Assembly: Ksp2Redux.dll
    Syntax
    public abstract class CommandCameraRenderHook : ICameraRenderHook
    Remarks

    The commands run in a render graph unsafe pass, which allows the temporary render textures, global state changes and procedural draws that the game's Built-in pipeline command buffers use. Where the old code targeted BuiltinRenderTextureType.CameraTarget or CurrentActive, use Color.
