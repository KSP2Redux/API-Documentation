    Class LegacyShaderRemap

    Finds materials that still reach a Built-in pipeline shader, logs them, and moves them to the URP port of the same name when one exists.

    Remarks

    With the install converted, stock content reaches only URP shaders and this finds nothing. It is the fallback for development installs that were not converted and for mod bundles built against the Built-in pipeline. A shader counts as Built-in when a pass uses a Built-in lighting mode (ForwardBase, Deferred and so on, in any case) or none of its subshaders runs on this device, unless it is one of URP's own hidden shaders, which a player build strips for the features the game leaves off (XR, HDR output, decal buffers). Unity's own unnamed error material is not reported. Loaded shaders are checked after bundle loads and scene loads, and about once a second, materials only while such a shader is loaded. The remap is on unless the game starts with -redux-no-legacy-shader-remap. The log is always on.
