    Class TerrainMeshSlots

    Hands out PQS mesh buffer slots to the quads that are drawn, the leaves of the quad tree.

    Inheritance
    object
    TerrainMeshSlots
    Namespace: Redux.Planets
    Assembly: Assembly-CSharp.dll
    Syntax
    public class TerrainMeshSlots
    Remarks

    A quad's mesh lives in its slot, so only leaves need one. Interior quads are never drawn, and a quad is meshed again when its children merge back into it. Slots are tracked per quad id and reused lowest first.

    Remarks

    Each slot holds one quad's mesh, about 39 KB of GPU memory, so Low takes about 466 MB and High 621 MB. Only the body the camera is on renders its terrain, so that is the whole cost.
