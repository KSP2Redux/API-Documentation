    Class VegetationMotionDraws

    The instanced vegetation draws of this frame, kept so BodyMotionVectorsPass can draw the same instances again with their motion vector pass.

    Inheritance
    object
    VegetationMotionDraws
    Namespace: Redux.Rendering
    Assembly: Ksp2Redux.dll
    Syntax
    public static class VegetationMotionDraws
    Remarks

    VegetationSystemPro draws vegetation with Graphics.DrawMeshInstancedIndirect, which URP's motion vector pass never picks up, so swaying grass and trees had only the motion of the ground under them. Each draw whose material has a PASS_NAME pass is recorded with its camera, instance buffer and arguments.
