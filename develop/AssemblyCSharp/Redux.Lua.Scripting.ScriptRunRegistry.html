    Class ScriptRunRegistry

    Tracks the script runs the in-game console (and CLI eval) starts, so the running script can read its own identity through the Script global and the host can cancel it.

    Inheritance

    ScriptRunRegistry

    public static class ScriptRunRegistry
    Remarks

    A "run" is one console or CLI execution, opened with BeginScriptRun(string, string, string) and keyed by an id. The host marks which run is executing with SetCurrentScriptRun(string) around each resume, so the Script global reads the right run off ambient state. Coroutines a run spawns are owned by ModCoroutineRunner (keyed by the same id), not tracked here. The static surface (BeginScriptRun(string, string, string), SetCurrentScriptRun(string), ClearCurrentScriptRun(string), CompleteScriptRun(string), CancelScriptRun(string), IsScriptRunActive(string)) is the contract the SpaceWarp console reaches by reflection through LuaScriptUtilityMgr.
