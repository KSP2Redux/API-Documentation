    Parameters
    Type Name Description
    Vector3 sunDirection

    The direction light arrives from.
    Color sunColor

    The colour of that light.
    float sunIntensity

    How strong that light is.
    Remarks

    Unlike the atmosphere, the cloud component is left running: it turns each layer against the wind, sizes them, orders them and binds their probes every frame, which is far more than is worth reproducing. Only what it gets wrong outside flight is written over. It assumes flight's fixed scaled space and a star light the menu does not have, so it would draw the clouds at the wrong size, lit white from straight up. This has to be called after the component's own update rather than before, or the frame's copy to the layers carries its values rather than these.
