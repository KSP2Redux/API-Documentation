    Class SwLibrary

    The Lua SW global. Mod scripts register lifecycle closures through it (for example SW:Init(fn)), and those closures fire at the matching SpaceWarp loading phase, before the mod's C# lifecycle method. The closures are wired onto the mod's SpaceWarpPluginDescriptor as plain Actions, so the descriptor never has to name a game-side script type.
