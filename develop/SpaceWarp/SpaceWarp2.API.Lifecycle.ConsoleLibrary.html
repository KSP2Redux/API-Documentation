    Class ConsoleLibrary

    The Lua Console global, through which a mod exposes values and functions to the in-game console.

    Inheritance

    Remarks

    Whatever a mod registers becomes a global on the shared console environment, so a console user can call a mod-provided function or read a mod-provided value by name. A registered function keeps the mod environment it was defined in, so it still sees that mod's globals when the console calls it.
