    Class ConfigHandle

    A live view over a bound config entry. Reads and writes go through the entry's config type, so scripts see rich values while storage holds the C# value the settings menu renders.

    Inheritance
    object
    ConfigHandle
    Namespace: SpaceWarp2.API.Config
    Assembly: SpaceWarp2.dll
    Syntax
    [MoonSharpUserData]
public sealed class ConfigHandle
    Remarks

    The handle is live, not a captured value: the settings menu or another mod can move the underlying entry, and value always reflects the current setting.

    Properties

    value

    The current value in the config type's rich Lua domain. Reading deserializes the stored value. Writing serializes, stores (which saves the file), and fires change callbacks.
