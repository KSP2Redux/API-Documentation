    Type Description
    IEnumerable<Type>

    Every type that loaded successfully.
    Remarks

    A mod assembly can reference a type that is not present at runtime, which makes System.Reflection.Assembly.GetTypes() throw System.Reflection.ReflectionTypeLoadException. The types that did load are still reachable on the exception, so this yields those and drops the ones that failed to load.
